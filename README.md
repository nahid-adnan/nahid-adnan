## 📌 Featured project

### 🏝️ [Tasmania Short-Stay Market Intelligence](https://github.com/nahid-adnan/Tasmania-short-stay-dashboard)

An interactive **Power BI** dashboard on Tasmania's short-term rental market — **5,293 listings**,
a **$145.3M** estimated revenue pool, across five linked report pages.

[![Tasmania dashboard](https://raw.githubusercontent.com/nahid-adnan/Tasmania-short-stay-dashboard/main/01-market-overview.png)](https://github.com/nahid-adnan/Tasmania-short-stay-dashboard)

| | |
|:---|:---|
| 🗺️ **Geographic** | Bubble map of estimated 12-month revenue by local government area |
| 🎚️ **What-if** | Repricing scenario driven by a disconnected parameter table |
| ⭐ **Hosts** | Larger portfolios charge more but rate lower — the counter-intuitive finding |
| 🔎 **Drill-through** | Region → listing-level register with an adjustable quality bar |

<sub>Power BI Desktop · DAX · what-if parameters · drill-through & drill-down · custom tooltip page · bookmarks</sub>
